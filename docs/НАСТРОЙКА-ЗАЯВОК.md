# Настройка заявок: почта, Telegram, ВК

Сайт **ermakcentr.ru** (Timeweb App Platform) + шлюз **api.ermakcentr.ru** (VPS Intelligent Pheasant).

---

## Часть A. VPS (147.45.147.90) — Telegram и ВК

### 1. Войти в консоль

Timeweb → **Облачные серверы** → **Intelligent Pheasant** → **Консоль**.

- `login:` → **root**
- `Password:` → пароль из вкладки **Доступ** (символы не видны — это нормально)

### 2. Скачать проект на сервер

```bash
apt-get update -qq && apt-get install -y -qq git
cd /opt
git clone https://github.com/workdanytanya-cloud/ermak-prepared-now.git
cd ermak-prepared-now/server
```

### 3. Создать файл с секретами

```bash
nano .env
```

Вставьте (подставьте свои значения):

```env
VK_GROUP_TOKEN=ваш_ключ_сообщества_вк
TELEGRAM_BOT_TOKEN=ваш_токен_из_BotFather
TELEGRAM_CHAT_ID=489781325
PORT=5055
```

Сохранить: **Ctrl+O**, Enter, **Ctrl+X**.

**Где взять VK_GROUP_TOKEN:** группа ВК → Управление → Работа с API → Ключ доступа (права: управление сообществом, стена).

**Telegram:** @BotFather → `/newbot` → токен. Chat ID — @userinfobot или id группы.

### 4. Запустить установку одной командой

```bash
bash bootstrap-leads.sh
```

Скрипт установит Node, запустит шлюз (pm2), спросит про DNS и выпустит SSL.

### 5. DNS (если ещё не сделали)

Timeweb → **Домены и SSL** → **ermakcentr.ru** → DNS-записи:

| Тип | Имя | Значение |
|-----|-----|----------|
| A | api | 147.45.147.90 |

Подождите 5–30 минут.

### 6. Проверка

В консоли VPS:

```bash
curl -sS https://api.ermakcentr.ru/health
```

Должно быть: `"ok":true`.

## Часть B. Timeweb App Platform (Ermak2.0) — связь с сайтом

**Настройки** → **Переменные окружения** → добавить:

| Переменная | Значение |
|------------|----------|
| `VITE_LEADS_SERVER_URL` | `https://api.ermakcentr.ru` |
| `VITE_WEB3FORMS_ACCESS_KEY` | ключ с [web3forms.com](https://web3forms.com) |

Почта Web3Forms: регистрация на **ermakcentrnsk@gmail.com** → создать форму → скопировать Access Key.

**Деплой** → пересобрать → дождаться «В сети».

На сайте: **Ctrl+Shift+R** → тестовая заявка.

## Что должно работать после настройки

| Канал | Как проверить |
|-------|----------------|
| Почта | Письмо на ящик, привязанный к Web3Forms (и спам) |
| Telegram | Сообщение боту в чат `TELEGRAM_CHAT_ID` |
| ВК | Пост на стене сообщества |
| Сайт | Нет жёлтых предупреждений про HTTPS-шлюз |

---

## Если что-то не работает

| Симптом | Решение |
|---------|---------|
| Жёлтое «нужен HTTPS-шлюз» | Не задан `VITE_LEADS_SERVER_URL` или не пересобрали сайт |
| `curl api.ermakcentr.ru` не отвечает | DNS, firewall, `pm2 list` → vk-gateway online |
| Почта не приходит | Новый ключ Web3Forms, спам, переменная в Timeweb |
| ВК не постит | Проверить `VK_GROUP_TOKEN`, права «стена» |

Логи на VPS: `pm2 logs vk-gateway`
