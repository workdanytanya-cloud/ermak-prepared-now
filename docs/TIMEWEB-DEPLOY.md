# Деплой на Timeweb App Platform (Ermak2.0)

## Настройки деплоя

| Параметр | Значение |
|----------|----------|
| Репозиторий | `workdanytanya-cloud/ermak-prepared-now` |
| Ветка | `main` |
| Команда сборки | `npm run build` |
| **Директория сборки** | **`dist`** |
| Node.js | 20 или 22 |

## Проверка после деплоя

1. https://ermakcentr.ru/build-id.txt — строка с хешем коммита (не HTML и не 404)
2. На главной Ctrl+U — имя JS-файла **не** `index-Bq5mEd4Y.js`

## Если сайт не обновляется

**Признак отката:** в шапке приложения «В сети» стоит старый коммит (например `1ae95d7`), хотя вы выбрали новый — значит **сборка нового коммита упала**, Timeweb оставил последний успешный.

1. **Деплой** → **История** — найдите попытку с новым коммитом, откройте **логи** (красная ошибка в конце)
2. **Настройки деплоя** → директория сборки строго **`dist`**
3. Версия Node.js: **20** или **22**
4. После успешного деплоя: https://ermakcentr.ru/build-id.txt — одна строка с хешем, **не** HTML и не 404
5. На главной Ctrl+U — JS-файл **не** `index-Bq5mEd4Y.js`

## Частая ошибка

Сборка проходит, но в панели указана неверная **директория сборки** — Timeweb публикует старые файлы. Для Vite всегда **`dist`**.
